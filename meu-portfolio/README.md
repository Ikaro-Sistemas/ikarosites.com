## 📋 Sobre o Projeto

Este projeto é uma Landing Page profissional desenvolvida para apresentar os serviços da **Ikaro Sistemas**. O objetivo é oferecer uma interface moderna, responsiva e de alta conversão para ofertar serviços de desenvolvimento de software, incluindo:

*   Lojas Virtuais (E-commerce)
*   Landing Pages de alta performance
*   Sistemas de Gestão
*   Chatbots e Automação

O projeto serve tanto como portfólio pessoal quanto como canal de captação de clientes reais.

## 🚀 Tecnologias Utilizadas

O desenvolvimento foi focado em performance e código limpo, utilizando as seguintes tecnologias:

*   **HTML5 Semântico:** Estruturação de conteúdo otimizada para SEO.
*   **CSS3 & Tailwind CSS:** Estilização moderna, responsiva e ágil.
*   **JavaScript (ES6+):** Interatividade, animações e manipulação do DOM.
*   **AOS (Animate On Scroll):** Biblioteca para animações fluidas ao rolar a página.
*   **VS Code:** Ambiente de desenvolvimento.

## ⚙️ Metodologia e Organização

Como Engenheiro de Software, a organização é fundamental. Este projeto foi gerenciado utilizando metodologias ágeis:

*   **Jira Software:** Utilizado para o gerenciamento do backlog, criação de user stories e acompanhamento das tarefas (Kanban).
*   **Versionamento:** Controle de versão para manter o histórico de evoluções do código.

## 🎨 Funcionalidades

- [x] **Menu Circular Interativo:** Navegação moderna e intuitiva.
- [x] **Carrossel de Depoimentos:** Feedback dinâmico de clientes.
- [x] **Design Responsivo:** Adaptável para Mobile, Tablet e Desktop.
- [x] **Animações de Entrada:** Elementos surgem suavemente na tela.
- [x] **Integração com WhatsApp:** Botões de Call-to-Action (CTA) diretos.

1. Clone este repositório.
2. Abra o arquivo `index.html` em seu navegador de preferência.
3. Para desenvolvimento, recomenda-se o uso da extensão "Live Server" no VS Code.
